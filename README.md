# Pedal Point

탄소 마일리지 기반 공공자전거 서비스 — 데이터베이스 과제 5조

공공자전거로 이동한 거리만큼 줄어든 탄소량을 계산해 마일리지로 적립하고, 다음 이용요금 결제 때 할인으로 사용한다.
이용자는 지도에서 대여소를 골라 빌리고, 반납하면서 결제하고, 자신이 줄인 탄소를 생활 속 수치로 확인한다.

## 실행

준비물: Python 3.11 이상, 실행 중인 MySQL 8.0.16 이상 (MariaDB 11.4 이상도 동작), 지도용 인터넷 연결

**`run.bat`을 더블클릭한다.** 처음 실행 때 자동으로 처리하는 일:

1. `.venv` 가상환경과 패키지 설치 (`requirements.txt`가 바뀌면 다시 설치)
2. `.streamlit/secrets.toml`이 없으면 예시를 복사하고 메모장을 연다 → MySQL 비밀번호를 넣고 저장
3. pedal DB가 없으면 `sql/GreenRide_DDL.sql` → `sql/GreenRide_DML.sql` 순서로 생성 (mysql 클라이언트 불필요)
4. Streamlit 실행 (브라우저가 열림)

| 명령 | 설명 |
|---|---|
| `run.bat` | 실행 (DB가 있으면 그대로 사용) |
| `run.bat --reset` | **pedal DB를 지우고** 시연 데이터로 다시 만든 뒤 실행 |

## 구성

| 구분 | 내용 |
|---|---|
| DB | MySQL `pedal` — 테이블 7개, FK 8개, CHECK 9개 (`docs/ERD.mwb`와 같은 구조) |
| 웹 | Python + Streamlit (이용자·관리자), pymysql, 비밀번호 bcrypt |
| 지도 | Leaflet + OpenStreetMap 타일 (API 키 불필요) |
| 화면 | PC 화면 + 모바일 전용 화면 (창 비율로 자동 전환), 라이트/다크 테마 |

app/admin_ops.py         관리자 기능 SQL

app/ui.py                공통 스타일·컴포넌트, 화면 모드 감지, 테마 전환

처음에는 운영체제 설정을 따르고, 해/달 버튼(사이드바, 모바일 상단 바, 로그인 화면 오른쪽 위)으로 바꾼다.
Streamlit은 테마를 바꿀 때 페이지를 새로 불러오므로 일회용 토큰(60초)으로 로그인을 이어받는다.

## 업무 규칙

기준값은 `app/rules.py`에 있고 시연 데이터와 같은 기준이다.

| 항목 | 규칙 |
|---|---|
| 요금 | 기본 60분 1,000원, 초과 30분마다 500원 (30분 미만도 30분) |
| 적립 | 이동거리(km) × 100P, 소수점 버림. 0P면 적립 기록 없음 |
| 할인 | 1P = 1원, 이용금액과 보유 마일리지 중 작은 값까지. 이번에 적립된 포인트는 다음 결제부터 |
| 대여 | 1인 1대, 정지 회원 불가, 운영 중 대여소의 대여 가능 자전거만 |
| 반납 | 운영 중이고 빈 거치대가 있는 대여소만, 이동거리 0 ~ 99.99km |
| 회원 | 행을 지우지 않고 상태만 바꾼다. 대여 중이면 정지·탈퇴 불가, 결제하지 않은 대여가 있으면 탈퇴 불가 |

- 대여 상태는 `rental_end_time`의 NULL 여부, 결제 대기는 반납됐지만 `payment` 행이 없는 대여다
- 적립 내역은 `mileage`, 사용 내역은 `payment_discount > 0`인 결제다. `user.user_mileage`는 결제와 같은 트랜잭션에서 `− 사용 + 적립`으로 갱신한다
- 대여, 반납·결제·적립은 각각 한 트랜잭션이고, 이용자·자전거·대여·대여소 행을 `SELECT … FOR UPDATE`로 잠근다
- 업무 규칙 위반은 안내 문구로, 그 밖의 DB 오류는 "처리 중 오류가 발생했습니다. 다시 시도해 주세요."로 보여준다

## 탄소 절감 체감

DB를 바꾸지 않고 이동거리로 계산한다.

- **줄인 탄소**: 이동거리 × 210g (자전거가 승용차 이동을 대신했다고 본다)
- **생활 속 환산**: 승용차 대신 달린 거리, 소나무 하루·1년 흡수량 (1그루 연 6.6kg, 산림청 기준)
- **나의 숲**: 누적 절감량으로 새싹(0) → 묘목(1kg) → 어린 나무(5kg) → 큰 나무(15kg) → 숲(40kg), 다음 단계까지 진행 막대
- **이번 달 목표** 3kg 게이지, 이용자 중 내 순위, 전체 이용자가 함께 줄인 탄소
- 홈·마이페이지 탄소 카드, 반납 화면 미리 보기, 결제 완료(단계가 오르면 축하 문구), 대여 내역의 이용별 탄소, 로그인 화면

## 대여소 좌표

DB 구조(station)에는 위도·경도가 없어서 좌표를 `app/station_coords.json`에 둔다. 시연 데이터 20곳은 대여소 이름 기준의
대략적인 실제 위치이고, 관리자가 대여소를 등록·수정할 때 지도를 눌러 정한 위치가 이 파일에 저장된다.
좌표가 없는 대여소는 지도 아래 버튼으로 고를 수 있다. `run.bat --reset`은 DB만 초기화하므로, 그 전에 등록한
대여소(21번 이후)의 좌표가 남아 있으면 같은 번호로 새로 등록한 대여소에 그 위치가 쓰인다.
